Process — how this was actually built

1. Research agent researches each app

A script sends every app to Claude with a web-search tool, asking for auth method, self-serve vs. gated access, API surface, MCP status, and a buildability verdict — each field required to cite a real source URL.

2. Verification pass samples the output

A second script pulls a random sample of the agent's results and re-checks every field against the cited URLs, marking each CORRECT / INCORRECT / UNVERIFIABLE — not just spot-checked by eye.

3. Disagreements get a human look

Anything the verifier flags as incorrect or unverifiable is manually re-checked before it's allowed into the pattern analysis below — the numbers reported are post-correction, not the agent's raw first pass.

4. Patterns are pulled from the corrected data

Only after verification does the aggregate analysis run — auth-method distribution, gated-vs-self-serve split by category, and common blockers, computed directly off results.json.
